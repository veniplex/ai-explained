# v3-alpha Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `v3-alpha/`, a guided path in seven chapters plus an epilogue that explains AI agents to complete beginners, with a map that grows chapter by chapter and ends as a small hub of 21 entries.

**Architecture:** Plain static site like v1-alpha: no build step, ES5-style scripts in IIFEs. Content lives in four data files that assemble `window.AE3`; five UI scripts build on a shared `window.V3` namespace (`sketch.js` → `map.js` → `story.js` → `guide-views.js` → `app.js`). A Node script (`scripts/check-v3.js`, tested with `node:test`) enforces the content rules from the spec.

**Tech Stack:** HTML, CSS, vanilla JavaScript, rough.js (vendored), Node ≥ 20 for the check script only.

**Spec:** `docs/superpowers/specs/2026-10-11-v3-alpha-design.md`

## Global Constraints

- `v1-alpha/` stays byte-for-byte unchanged (`git diff --stat origin/main -- v1-alpha` prints nothing).
- No build step, no npm dependencies, no external requests, no cookies. `localStorage` only for `ae-theme` and `ae3-checklist`.
- Scripts are ES5 style (`var`, `function`), wrapped in IIFEs, like v1-alpha.
- Styling follows `v1-alpha/DESIGN.md` (copied to `v3-alpha/DESIGN.md` in Task 8): tokens instead of raw values (`--fs-*`, `--r-*`, `--dur-*`, `--z-*`), the shared pieces (`.btn`, `.eyebrow`, `.badge`, `.card`, `.zdot`, `.chip`, `.tag-*`), state classes `is-*`, variants as suffixes (`ctx-seg-strong`, `link-type-video`).
- Theme: the `<head>` script always sets `data-theme` (the saved choice, else the system setting); the stylesheet reads only `data-theme`.
- Content lives in `v3-alpha/assets/js/data/*.js`, not in a `data.js`: `scripts/validate-data.js` (v1 schema) only checks folders that have a `data.js`, and `scripts/check-v3.js` checks v3.
- Preview: the `site-v3` entry in `.claude/launch.json` (`python -m http.server 8001`), so it does not collide with the `site` server (port 8000) another session may run.
- English copy. Snapshot "October 2026". Dated facts carry month and year.
- Budgets: core path ≤ 2,500 words; entry levels 1 and 2 ≤ 150 words; ≤ 4 entries per chapter; ≤ 22 entries; ≤ 5 guides; ≤ 4 facts per entry; glossary ≤ 60 terms; learn ≤ 5 items per group.
- Layout: two-column story at ≥ 1024 px; five-column hub at ≥ 1080 px; no horizontal scroll at 375 px.
- Respect `prefers-reduced-motion`, keyboard use, light and dark themes.
- Chapter ids, in order: `chef`, `counter`, `tools`, `loop`, `recipes`, `locks`, `helpers`, `kitchen-ops`; `n` runs 1 to 8; chapter 8 is shown as "Epilogue" / "E".
- Deep links: `#ch-1` … `#ch-7`, `#ch-e`, `#map`, `#e-<entry id>`, `#guide-<compare|build|glossary|learn|about>`.

**Refinements of the spec's data model (same content, different files):** dated facts, sources, the merged v1 block names and search synonyms live in `AE3.sources[<entry id>]` (generated file `data/sources.js`) instead of `entries[id].deeper`, so the hand-written entry text stays readable. Chapters gain `term` (the real-world name) and `zone` (colour key); `AE3` gains `hero.minutes`, `figures.contextBars` and `guideList` (titles of the five guides).

## Review Focus

1. **Scrolling back up** through the chapters: later zones must disappear again from the map beside the text, with no half-drawn outlines and the current chapter still highlighted. Test: Task 10, Step 5.
2. **Crossing 1024 px** (rotating a tablet, resizing a window): the sticky map hides, the "map so far" sketches appear and build lazily, nothing stays blank or appears twice. Test: Task 10, Step 6.
3. **Deep link on first load** (`#e-skills`, `#ch-5`, `#guide-glossary`): the drawer or sheet opens, or the page lands on the chapter title below the sticky bar. Test: Task 11, Step 6.
4. **Reduced motion**: no stroke animation, the loop token rests, and every revealed piece is fully visible (no element stuck at opacity 0). Test: Task 12, Step 4.
5. **Search for merged v1 terms** ("playbooks", "RAG", "A2A", "fine-tuning") finds the v3 entry that absorbed them. Test: Task 11, Step 5.

#!/usr/bin/env node
/* Content checks for v3-alpha. Run from the repository root: node scripts/check-v3.js
   Exits with code 1 and lists every problem when a check fails. Rules come from
   docs/superpowers/specs/2026-10-11-v3-alpha-design.md (sections 6, 7 and 10). */
"use strict";
const fs = require("node:fs");
const path = require("node:path");
const vm = require("node:vm");

const CHAPTER_IDS = ["chef", "counter", "tools", "loop", "recipes", "locks", "helpers", "kitchen-ops"];
const LIMITS = { coreWords: 2500, entryWords: 150, entriesPerChapter: 4, entries: 22, guides: 5, facts: 4, glossary: 60, learnPerGroup: 5, recap: 5 };
const V3_FILES = ["data/core.js", "data/entries.js", "data/sources.js", "data/guides.js"];

function loadScripts(files) {
  const ctx = { window: {} };
  vm.createContext(ctx);
  files.forEach((f) => vm.runInContext(fs.readFileSync(f, "utf8"), ctx, { filename: f }));
  return ctx.window;
}
function loadV1(root) { return loadScripts([path.join(root, "v1-alpha/assets/js/data.js")]).AE; }
function loadV3(root) { return loadScripts(V3_FILES.map((f) => path.join(root, "v3-alpha/assets/js", f))).AE3; }

// Inline markup to plain text: [[id|label]] -> label, [[id]] -> id, [t](url) -> t, **b** -> b, `c` -> c.
function plain(text) {
  return String(text || "")
    .replace(/\[\[([^\]|]+)\|([^\]]+)\]\]/g, "$2")
    .replace(/\[\[([^\]]+)\]\]/g, "$1")
    .replace(/\[([^\]]+)\]\(https?:[^)\s]+\)/g, "$1")
    .replace(/\*\*([^*]+)\*\*/g, "$1")
    .replace(/`([^`]+)`/g, "$1");
}
function wordCount(...parts) {
  return parts.flat(Infinity).reduce((n, t) => n + (plain(t).match(/\S+/g) || []).length, 0);
}
function eachString(value, fn, at) {
  if (typeof value === "string") fn(value, at);
  else if (Array.isArray(value)) value.forEach((v, i) => eachString(v, fn, at + "[" + i + "]"));
  else if (value && typeof value === "object") Object.keys(value).forEach((k) => eachString(value[k], fn, at + "." + k));
}

function check(v1, v3) {
  const errors = [];
  const err = (msg) => errors.push(msg);
  const entries = v3.entries || {};
  const ids = Object.keys(entries);
  const chapters = v3.chapters || [];
  const has = (id) => Object.prototype.hasOwnProperty.call(entries, id);
  const g = v3.guides || {};

  // 1. Chapters
  const chapterIds = chapters.map((c) => c.id);
  if (chapterIds.join() !== CHAPTER_IDS.join()) err("chapters: expected " + CHAPTER_IDS.join(", ") + ", got " + chapterIds.join(", "));
  chapters.forEach((c, i) => {
    if (c.n !== i + 1) err("chapter " + c.id + ": n should be " + (i + 1));
    ["title", "problem", "kitchen", "example"].forEach((f) => { if (!c[f]) err("chapter " + c.id + ": missing " + f); });
    if (!Array.isArray(c.real) || !c.real.length) err("chapter " + c.id + ": missing real");
    const list = c.entries || [];
    if (list.length > LIMITS.entriesPerChapter) err("chapter " + c.id + ": introduces " + list.length + " entries, limit " + LIMITS.entriesPerChapter);
    list.forEach((id) => { if (!has(id)) err("chapter " + c.id + ": unknown entry " + id); });
  });

  // 2. Entries
  if (ids.length > LIMITS.entries) err("entries: " + ids.length + ", limit " + LIMITS.entries);
  ids.forEach((id) => {
    const e = entries[id];
    const homes = chapters.filter((c) => (c.entries || []).indexOf(id) !== -1);
    if (homes.length !== 1) err("entry " + id + ": listed in " + homes.length + " chapters, expected 1");
    else if (e.chapter !== homes[0].id) err("entry " + id + ": chapter is " + e.chapter + " but listed in " + homes[0].id);
    ["name", "label", "kitchen", "short", "example"].forEach((f) => { if (!e[f]) err("entry " + id + ": missing " + f); });
    if (!Array.isArray(e.how) || !e.how.length) err("entry " + id + ": missing how");
    if (!Array.isArray(e.forYou) || e.forYou.length < 1 || e.forYou.length > 3) err("entry " + id + ": forYou needs 1 to 3 items");
    const d = e.deeper || {};
    if (!Array.isArray(d.details) || !d.details.length) err("entry " + id + ": missing deeper.details");
    if (!Array.isArray(e.from) || !e.from.length) err("entry " + id + ": missing from");
    else if ((d.includes || []).length < e.from.length - 1) err("entry " + id + ": needs an includes line for each merged block");
    const words = wordCount(e.kitchen, e.short, e.how, e.example, e.forYou);
    if (words > LIMITS.entryWords) err("entry " + id + ": levels 1 and 2 have " + words + " words, limit " + LIMITS.entryWords);
    (e.related || []).forEach((r) => { if (!has(r)) err("entry " + id + ": unknown related " + r); });
  });

  // 3. Every v1 block maps to exactly one entry
  const owner = {};
  ids.forEach((id) => (entries[id].from || []).forEach((b) => { (owner[b] = owner[b] || []).push(id); }));
  Object.keys(v1.blocks).forEach((b) => {
    const o = owner[b] || [];
    if (o.length !== 1) err("v1 block " + b + ": mapped to " + (o.length ? o.join(", ") : "no entry"));
  });
  Object.keys(owner).forEach((b) => { if (!v1.blocks[b]) err("from: unknown v1 block " + b); });

  // 4. References
  eachString(v3, (s, at) => {
    const re = /\[\[([^\]|]+)(?:\|[^\]]+)?\]\]/g;
    let m;
    while ((m = re.exec(s))) if (!has(m[1])) err(at + ": unknown link [[" + m[1] + "]]");
  }, "AE3");
  (v3.recap || []).forEach((r, i) => (r.entries || []).forEach((id) => { if (!has(id)) err("recap " + (i + 1) + ": unknown entry " + id); }));
  (g.glossary || []).forEach((t) => { if (t.entry && !has(t.entry)) err("glossary " + t.term + ": unknown entry " + t.entry); });
  ((g.compare || {}).rows || []).forEach((r) => { if (!has(r.entry)) err("compare " + r.name + ": unknown entry " + r.entry); });
  const b = g.build || {};
  (b.recipe || []).forEach((r) => (r.entries || []).forEach((id) => { if (!has(id)) err("recipe " + r.title + ": unknown entry " + id); }));
  (b.patterns || []).forEach((p) => (p.entries || []).forEach((id) => { if (!has(id)) err("pattern " + p.id + ": unknown entry " + id); }));
  (b.flows || []).forEach((f) => (f.route || []).forEach((st) => { if (!has(st.e)) err("flow " + f.name + ": unknown entry " + st.e); }));
  (b.protocols || []).forEach((p) => { if (p.entry && !has(p.entry)) err("protocol " + p.name + ": unknown entry " + p.entry); });

  // 5. Budgets
  const core = wordCount(v3.hero && v3.hero.title, v3.hero && v3.hero.line, v3.example && v3.example.task,
    chapters.map((c) => [c.title, c.problem, c.kitchen, c.real, c.example]),
    (v3.recap || []).map((r) => [r.t, r.d]));
  if (core > LIMITS.coreWords) err("core path: " + core + " words, limit " + LIMITS.coreWords);
  if ((v3.recap || []).length !== LIMITS.recap) err("recap: expected " + LIMITS.recap + " items");
  if ((v3.guideList || []).length > LIMITS.guides) err("guides: " + v3.guideList.length + ", limit " + LIMITS.guides);
  if ((g.glossary || []).length > LIMITS.glossary) err("glossary: " + g.glossary.length + " terms, limit " + LIMITS.glossary);
  (g.learn || []).forEach((grp) => { if (grp.items.length > LIMITS.learnPerGroup) err("learn " + grp.title + ": " + grp.items.length + " items, limit " + LIMITS.learnPerGroup); });

  // 6. Sources and facts
  const src = v3.sources || {};
  ids.forEach((id) => {
    const s = src[id];
    if (!s) { err("sources: missing " + id); return; }
    if ((s.facts || []).length > LIMITS.facts) err("sources " + id + ": " + s.facts.length + " facts, limit " + LIMITS.facts);
    const seen = new Set();
    (s.sources || []).forEach((l) => {
      ["title", "by", "url", "year"].forEach((f) => { if (!l[f]) err("sources " + id + ": source without " + f + " (" + (l.url || l.title) + ")"); });
      if (seen.has(l.url)) err("sources " + id + ": duplicate " + l.url);
      seen.add(l.url);
    });
  });

  // 7. Glossary terms must appear in the v3 text
  const corpus = [];
  eachString({ c: v3.chapters, e: v3.entries, r: v3.recap }, (s) => corpus.push(plain(s).toLowerCase()), "");
  const text = corpus.join(" \n ");
  (g.glossary || []).forEach((t) => {
    const head = t.term.replace(/\s*\(.*\)\s*$/, "").toLowerCase();
    if (text.indexOf(head) === -1) err("glossary " + t.term + ": term does not appear on the page");
  });

  return errors;
}

module.exports = { CHAPTER_IDS, LIMITS, plain, wordCount, check, loadV1, loadV3 };

if (require.main === module) {
  const root = path.resolve(__dirname, "..");
  let errors;
  try { errors = check(loadV1(root), loadV3(root)); } catch (e) { errors = ["could not load data: " + e.message]; }
  if (errors.length) { console.error(errors.length + " problem(s):\n- " + errors.join("\n- ")); process.exit(1); }
  console.log("v3-alpha content checks passed.");
}
```

/* One-off: builds v3-alpha data files from v1-alpha. Not kept in the repo.
   Usage, from the repository root: node "$SCRATCH/migrate-v1.js" */
"use strict";
const fs = require("node:fs");
const path = require("node:path");
const vm = require("node:vm");
const root = process.cwd();

// Spec section 6.1: v3 entry id -> merged v1 block ids (the first one is the main block).
const MAP = {
  model: ["model", "fine-tuning"], reasoning: ["reasoning"],
  context: ["context-window", "context-engineering"], prompt: ["system-prompt"],
  tools: ["tools", "computer-use"], mcp: ["mcp"],
  "agent-loop": ["agent-loop", "planning", "verification"], harness: ["harness", "surfaces", "sdk"],
  instructions: ["instructions"], skills: ["skills", "playbooks", "commands", "plugins"],
  knowledge: ["rag", "embeddings", "search"], memory: ["memory", "compaction"],
  permissions: ["permissions", "hitl"], sandbox: ["sandbox"], hooks: ["hooks", "guardrails"], security: ["security"],
  team: ["subagents", "multi-agent", "a2a", "workflows"], background: ["long-running", "triggers"],
  evals: ["evals", "observability"], cost: ["cost", "provider"], governance: ["governance"]
};
const TO = {};
Object.keys(MAP).forEach((e) => MAP[e].forEach((b) => { TO[b] = e; }));

const ctx = { window: {} };
vm.createContext(ctx);
vm.runInContext(fs.readFileSync(path.join(root, "v1-alpha/assets/js/data.js"), "utf8"), ctx);
const D = ctx.window.AE;
Object.keys(D.blocks).forEach((b) => { if (!TO[b]) throw new Error("unmapped v1 block " + b); });

// [[v1-id]] -> [[v3-id|v1 label]], so sentences still read naturally.
function remap(s) {
  return s.replace(/\[\[([a-z0-9-]+)(\|[^\]]+)?\]\]/g, (m, id, lab) => {
    const e = TO[id];
    if (!e) throw new Error("unknown v1 link " + id);

/* One-off: keeps only glossary terms that appear in the v3 text (spec 7), at most 60.
   Terms used in the chapters come first, then terms used only in entries. */
"use strict";
const fs = require("node:fs");
const path = require("node:path");
const root = process.cwd();
const { plain, loadV3 } = require(path.join(root, "scripts/check-v3.js"));
const A = loadV3(root);

// Same corpus as the check script: every string value, as plain lower-case text.
function textOf(v) {
  const out = [];
  (function walk(x) { if (typeof x === "string") out.push(plain(x)); else if (x && typeof x === "object") Object.values(x).forEach(walk); })(v);
  return out.join(" \n ").toLowerCase();
}
const core = textOf([A.chapters, A.recap]);
const all = core + textOf(A.entries);
const head = (t) => t.term.replace(/\s*\(.*\)\s*$/, "").toLowerCase();

const inCore = A.guides.glossary.filter((t) => core.indexOf(head(t)) !== -1);
const inEntries = A.guides.glossary.filter((t) => core.indexOf(head(t)) === -1 && all.indexOf(head(t)) !== -1);
const kept = inCore.concat(inEntries).slice(0, 60).sort((a, b) => a.term.localeCompare(b.term, "en", { sensitivity: "base" }));
const dropped = A.guides.glossary.filter((t) => kept.indexOf(t) === -1).map((t) => t.term);

const file = path.join(root, "v3-alpha/assets/js/data/guides.js");
const src = fs.readFileSync(file, "utf8");
const start = src.indexOf("window.AE3.guides = ");
const guides = JSON.parse(JSON.stringify(A.guides));
guides.glossary = JSON.parse(JSON.stringify(kept));
fs.writeFileSync(file, src.slice(0, start) + "window.AE3.guides = " + JSON.stringify(guides, null, 2) + ";\n");
console.log("kept", kept.length, "· dropped", dropped.length + ":", dropped.join(", "));
```

    var current = 1;
    function fit() {
      var inner = $(".story-map-inner", aside);
      inner.style.zoom = "";

      if (n === current) return;
      current = n;
      sticky.setStage(n, n);
      fit();

      }, { rootMargin: "-45% 0px -50% 0px" });
      $$(".chapter", chapters).forEach(function (el) { io.observe(el); });
    } else {
      sticky.setStage(8, null);

    window.addEventListener("resize", fit);
    if (document.fonts && document.fonts.ready) document.fonts.ready.then(fit);
    requestAnimationFrame(fit);

    var boxes = $$(".mini-map", chapters);
    function build(box) {
      if (box._built) return;
      box._built = true;
      var n = +box.getAttribute("data-mini");
      box.appendChild(V3.map.create({ layout: "tall", mini: true, ring: false, stage: n, current: n }).el);
    }
    if (!("IntersectionObserver" in window)) { boxes.forEach(build); return; }
    var io = new IntersectionObserver(function (list) {
      list.forEach(function (en) { if (en.isIntersecting) { build(en.target); io.unobserve(en.target); } });
    }, { rootMargin: "600px 0px" });
    boxes.forEach(function (b) { io.observe(b); });
  }

    sk.append(main, [hero(), h("div", { class: "story" }, chapters, aside), hub()]);
    track(chapters, sticky, aside);
    lazyMinis(chapters);
  }

# Agentic AI, Explained (v3-alpha)

> Work in progress. A new version of the site; [v1-alpha](../v1-alpha/) stays online as the full reference.

A guided explanation of AI agents for people who are new to AI, as of **October 2026**. One restaurant kitchen and one running example ("find the three cheapest flights to Lisbon in May…") carry the reader through seven short chapters and an epilogue: the model, the context, tools, the agent loop, know-how and memory, guardrails, teams and autopilot, and running it well. A hand-drawn map grows beside the text, one piece per chapter, and ends as a map of the whole kitchen.

Every term opens in three levels: a picture and one sentence; how it works, what it means in the example and for you; and "Go deeper" with details for builders, dated facts and checked sources.
