Every building block of an AI agent, on one map

An agent is a language model that uses tools in a loop until a goal is reached. Everything else you hear about (skills, playbooks, MCP, RAG, memory, hooks, sub-agents) exists to give that loop the right context, the right capabilities and the right limits. This page shows each block, where it sits, and the moment it enters a run.

agent = model + harness(loop · context · control) + tools + know-how The model decides what to do next. The harness does everything else.

Five ideas that explain most of it

  1. 1The model is stateless.On every turn the harness re-sends the whole context. Anything not in that request does not exist for the model.
  2. 2Context is the bottleneck.Quality drops as the context window fills. Skills, sub-agents, compaction and RAG are all ways to load the right tokens at the right time.
  3. 3Prompts suggest; code enforces.Instructions guide behaviour. Hooks, permissions and sandboxes guarantee it.
  4. 4Start simple and climb only with evidence.A single call beats a workflow, and a workflow beats an autonomous agent, until your evals show otherwise.
  5. 5Give the agent a way to check its work.Tests, linters, screenshots and reviewers turn plausible output into verified output.

    What the model actually sees

    The context window is the agent's entire working memory for a turn. These bars show what fills it during a long task, as illustrative shares of a 200,000-token window. Compare the middle bar with the bottom one: that difference is context engineering.

    Easily confused

    Skill, tool, MCP server, plugin, hook: what is the difference?

    They all extend an agent, but they are triggered by different parties, enter the context at different moments and cost different amounts of it. Only some of them are deterministic.

    Context cost refers to tokens in the model's context window. “Deterministic” means the behaviour is guaranteed by code rather than by the model's judgement. For a worked example, watch Anthropic's Tool, skill, or subagent? Decomposing an agent that outgrew its prompt (2026).
